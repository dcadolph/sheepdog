Meet Tug, the border collie who takes your meetings seriously. He lives in your menu bar, gives you a heads-up when a meeting is near, and counts down until it’s time. Ignore him, and he’ll take over your screen. He even remembers what you were working on so you can pick up right where you left off afterward. Once you join, Tug settles down.

// Retry uploads job until it succeeds or the attempts run out.
func (q *Queue) Retry(ctx context.Context, job Job) error {
	backoff := q.base
	for attempt := 1; attempt <= q.max; attempt++ {
		err := q.upload(ctx, job)
		if err == nil {
			return nil
		}
		if !errors.Is(err, ErrTransient) {
			return fmt.Errorf("upload %s: %w", job.ID, err)
		}
		select {
		case <-ctx.Done():
			return ctx.Err()
		case <-time.After(backoff):
		}
		
	}
	return ErrExhausted
}

// Backoff reports how long the next attempt waits.
func (q *Queue) Backoff(attempt int) time.Duration {
	return min(q.base<<(attempt-1), q.ceiling)
}

You already have reminders.

Calendar, Outlook, Teams and Slack all ping you before a meeting. So does every other app, all day, in the same corner of the screen. Heads down on something hard, or bouncing between ten things, those pings slide by. Sheepdog has one job. Tug gets louder as the meeting gets closer and takes the whole screen when it's time, so you can't miss it unless you wave him off.

Works with what you already use

Your calendars. Your meeting apps.

sheepdog reads every calendar macOS Calendar knows about, and signs in to Microsoft directly for the ones it does not show. When it is time, Join opens the link it found in the invite, straight into the Zoom or Teams app.
